# AZURE-LABS
# Azure Cloud Labs Portfolio

## Overview

This repository documents hands-on labs and projects completed to develop practical experience with Microsoft Azure services and cloud infrastructure workflows. The exercises focus on deploying compute resources, configuring networking, managing storage and databases, and exploring platform services such as serverless functions and container deployment.

These labs demonstrate foundational familiarity with Azure environments and reinforce cloud administration and solution deployment concepts.
